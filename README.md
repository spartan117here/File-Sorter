# ⚡ Sortify — Smart Desktop File Organizer

> Organize your files effortlessly with an intelligent desktop application built using **React + Electron**.

Sortify is a modern desktop utility that helps you instantly organize cluttered folders into a clean, structured workspace. With smart categorization, interactive analytics, drag-and-drop support, and one-click automation, keeping your files organized has never been easier.

---

# ✨ Features

## 📂 Smart File Organization

Automatically sorts files into dedicated folders based on file type.

Supported categories include:

- 🖼️ Images
- 📄 Documents
- 🎬 Videos
- 🎵 Audio
- 💻 Code Files
- 📦 Archives
- 📊 Spreadsheets
- 📽️ Presentations
- 📁 Others

---

## 📥 Drag & Drop Folder Support

Simply drag a folder into Sortify to begin organizing.

Or choose a folder manually using the built-in folder picker.

---

## ⚡ Smart Mode

Enable Smart Mode to automatically:

- Scan the selected folder
- Analyze its contents
- Organize files instantly

Everything happens with minimal user interaction.

---

Visualize your storage using an interactive dashboard.

Includes:

- Total Files
- Total Storage Used
- Largest File Category
- Interactive Storage Distribution Chart
- Category-wise File Count
- Storage Percentage Breakdown

## 🔍 Quick Insights

Instantly identifies:

Supports:

# 🚀 Installation

## Download

Download the latest installer from the **Releases** page.

1. Open the **Releases** section of this repository.
2. Download the latest **Sortify Setup (.exe)** installer.
3. Install and launch the application.

---

## Run From Source

Clone the repository

```bash
git clone https://github.com/spartan117here/File-Sorter.git
```

Navigate into the project

```bash
cd File-Sorter
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Run Electron

```bash
npm run electron
```

Build production files

```bash
npm run build
```

Generate Windows installer

```bash
npm run dist
```
